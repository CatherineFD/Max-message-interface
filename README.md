# Тестовое задание для Грин-Апи

## 📝 Описание проекта

Данный репозиторий содержит решение тестового задания для компании **Грин-Апи**.

**Задача:** В рамках тестового задания требуется разработать пользовательский интерфейс для
отправки и получения сообщений в MAX.

---

## Стек технологий

- React 19+
- TypeScript
- Vite
- Yarn
- Ant Design
- MobX
- React Router DOM

---

## Требования

Перед началом работы убедитесь, что у вас установлены:

- **Node.js** версии `18.x` или выше ([скачать](https://nodejs.org/))
- **Yarn** (рекомендуется версия `1.22.x` или `4.x`)

Проверка версий:

```bash
node -v
yarn -v
```

---

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/CatherineFD/Max-message-interface
cd max-message-interface
```

2. Установите зависимости:

```bash
yarn install
```

---

## Настройка переменных окружения (.env)

Для работы приложения необходимо создать файл `.env` в корне проекта и добавить переменную с URL API.

Создайте файл `.env` рядом с `package.json`:

Файл `.env` **не должен** попадать в репозиторий. Убедитесь, что он указан в `.gitignore`:

```bash
# .gitignore
.env
.env.local
.env.*.local
```

---

## Локальный запуск

Запуск проекта в режиме разработки:

```bash
yarn dev
```
После запуска откройте в браузере: http://localhost:5173/Max-message-interface/

---

## Сборка и предпросмотр

Компиляция и сборка проекта:

```bash
yarn build
```

Локальный предпросмотр собранной версии:

```bash
yarn preview
```

## Структура основных скриптов

